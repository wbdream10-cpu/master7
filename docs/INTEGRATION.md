# 普通平台通用接入合同 v1

仅适用于本项目独立 Node 运行版。默认连接表和事件表为空；不发送外部请求，不使用任何实际供应商。没有预置账号、连接密钥、照片或演示事件。不要根据网页外观或 HTTP 200 判断业务通过。

## 浏览器前后台 API

- `GET /api/v1/me`：登录后返回 `id`、`username`、`role`；未登录 401。
- `GET /api/portal`：读取当前用户有权访问的公告、申请及工作空间信息。
- `POST /api/portal`：使用 JSON、同源 `Origin`、`X-Portal-Request: 1`。支持创建服务申请，老板可创建/编辑/发布公告、回复申请、分配已核实成员、保存 Logo。身份从 HttpOnly 会话读取，拒绝前端伪造角色或用户 ID。详细动作见 `app/api/portal/route.ts`。
- 客户只能读取自己工作空间已发布公告及自己的申请。老板只能在通过检查的工作空间操作资源。

这些是浏览器会话 API；没有把客户或老板密码变成第三方 API 密钥。不要把浏览器 Cookie、恢复码或密码交给外部服务。

## 老板配置连接

老板通过 `/connections` 创建通道，或者调用 `POST /api/v1/connections`。需老板登录、同源 Origin、JSON、`X-Portal-Request: 1`。

```json
{"id":"example-hook","tenantId":"main","keyEnv":"PORTAL_HOOK_EXAMPLE","enabled":true}
```

以上仅为文档示例，不自动创建记录。`id` 是 3–40 位小写字母/数字/下划线/连字符；`keyEnv` 只接受 `PORTAL_HOOK_` 前缀环境变量名。实际至少 32 字节的随机签名密钥由部署负责人保存在服务器的同名秘密环境变量中，不通过网页填写，也不写入仓库。为每个连接配置不同密钥。密钥变更后需按部署平台规则部署生效，并协调发送方切换。

保存只配置接收通道，不连接外部服务。已有连接不能跨工作空间移动。设 `enabled:false` 立即拒绝后续事件。默认最多 100 个连接。

`GET /api/v1/connections` 仅老板可访问，返回连接状态与最近 100 个事件元数据，不返回密钥和事件正文。`configured` 仅表示环境变量符合长度条件，不代表第三方连接验收成功。

## 签名事件入口

`POST /api/v1/hooks/{connectionId}`，不依赖浏览器 Cookie/Origin，必须提供以下请求头：

| 请求头 | 值 |
|---|---|
| `Content-Type` | `application/json` |
| `X-Portal-Timestamp` | 10 位 Unix 秒，服务器时间前后 300 秒 |
| `X-Portal-Event-Id` | 发送方提供的唯一 ID，1–100 位字母/数字/`_.:-` |
| `X-Portal-Signature` | `sha256=` 加 64 位小写十六进制 HMAC |

签名原文为 UTF-8 字节串 `timestamp + '.' + eventId + '.' + 原始请求体`，使用该连接独立的 HMAC-SHA256 密钥。签名覆盖事件 ID；不要先解析再重新序列化请求体。发送方和接收方须保持时间同步。

请求体上限 16 KB：

```json
{"type":"service.updated","data":{"reference":"external-reference"}}
```

`type` 仅接受 1–80 位字母/数字/`_.:-`，`data` 必须为 JSON 对象。不得发送密码、银行卡完整资料、私钥或不需要的个人资料。发送方不能用正文指定工作空间；归属取服务器保存的连接配置。

| 返回 | 含义 |
|---|---|
| 202，`accepted:true, processed:false` | 已存储，尚未处理业务 |
| 202，`duplicate:true, processed:false` | 相同连接、ID 和原始正文已收到，无重复存储 |
| 409 | 同一事件 ID 对应不同原始正文，需人工排查 |
| 401 | 签名或时间窗口无效 |
| 400 / 413 / 415 | 正文格式错误、过大或媒体类型错误 |
| 429 | 入口达到限速，发送方稍后带新时间戳与签名重试 |
| 503 | 未启用通道或签名密钥缺失 |
| 507 | 事件存储达到 10,000 条上限，需负责人处理 |

当前每来源 IP 最多 120 次/15 分钟，每连接最多 1,000 个新事件/15 分钟，使用数据库限速。反向代理下来源 IP 可能共享，不信任任意 X-Forwarded-For；接手人员需根据可信代理架构验收容量。无需重试确定性 4xx；503/429/网络故障可采用退避重试。每次重试用新时间戳重新签名，保留相同事件 ID 与原始正文。

## 业务适配由接手人员完成

本通道只验签、判重、保存事件，未实现业务处理器、外发请求、消息队列消费者或供应商协议转换。每个真实供应商需另建适配器，按其官方协议验证原始签名，再映射内部数据合同。不要把本说明中的通用签名强加给不支持它的供应商。

上线前分别验收未登录拒绝、客户无法管理连接、跨工作空间拒绝、签名/时钟、重复事件、停用连接、数据库持久性、限速和备份。只有通过实际业务状态核对，才可把相应业务标记为完成。
